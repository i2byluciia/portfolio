# Light · Logic · Create

Portfolio personal de **Luciia**, donde se encuentran tres partes de mi forma de trabajar y crear:

**Light · Logic · Create**

## Sobre el proyecto

Este portfolio nace de la idea de reunir en un mismo espacio mis diferentes áreas de interés: la **iluminación escénica**, la **informática** y los **proyectos creativos y personales**.

Más que mostrar únicamente resultados, el objetivo es enseñar cómo trabajo, qué herramientas utilizo y las cosas que voy aprendiendo y construyendo por el camino.

## Secciones

* **About Me** — Una pequeña presentación y mi forma de entender el trabajo y la creación.
* **Light** — Experiencia en iluminación escénica, trabajos, herramientas y flujo de trabajo.
* **Logic** — Informática, desarrollo, bases de datos, sistemas y proyectos.
* **Create** — Proyectos personales, fotografía, experimentación e ideas.
* **Contact** — Formas de contacto y enlaces profesionales.

## Diseño

La identidad visual del portfolio está inspirada en una mezcla de **tecnología, iluminación y elementos hechos a mano**.

La paleta combina tonos papel y carbón con gamas ámbar, doradas y violetas.

Las tipografías utilizadas son:

* **Cormorant Garamond** — Títulos
* **Inter** — Texto
* **Caveat** — Notas y elementos manuscritos
* **JetBrains Mono** — Código y elementos técnicos
